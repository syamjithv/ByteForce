Deadlocks & Coffman Prevention

8 min read

A deadlock occurs when a set of processes are blocked because each process is holding a resource and waiting for another resource held by another process.

Java // Resource Allocation Hierarchy Acyclic Guarantee 
public void acquireResources(Resource r1, Resource r2) {
    // Prevent circular wait by enforcing strict global acquisition ordering
    Resource first = r1.getId() < r2.getId() ? r1 : r2;
    Resource second = r1.getId() < r2.getId() ? r2 : r1;
    
    first.lock();
    second.lock(); // No cycle possible in Wait-For Graph
}

ACTIVE RECALL CUE Computer Networks
What is the fundamental architectural difference between TCP and UDP?
TCP (Transmission Control)

Connection-oriented, 3-way handshake, guaranteed in-order delivery, flow & congestion control. Used for HTTP, SSH, DB connections.

UDP (User Datagram)

Connectionless, minimal 8-byte header overhead, no delivery or order guarantee. Best for DNS lookups, VoIP, real-time gaming.

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[] { map.get(complement), i };
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }
}

TECHNICAL ROUND • SYSTEM FUNDAMENTALS Core Discussion
"Explain the difference between a process and a thread, and how context switching differs between them."
1.
Memory Space: Processes have separate virtual address spaces (code, data, heap). Threads within the same process share heap, globals, and open file descriptors, maintaining only their own stack and registers.
2.
Switching Overhead: Process context switch requires invalidating the TLB (Translation Lookaside Buffer) and switching memory mapping tables. Thread switch retains cache and TLB mappings, making it significantly faster.
Interviewer Follow-up Trap: Be prepared to explain Inter-Process Communication (IPC) techniques such as pipes, message queues, and shared memory.
